# ✅ To-Do List Web App

A simple and responsive **To-Do List Web Application** built using **HTML, CSS, and JavaScript**. This application allows users to add, complete, delete, and filter tasks while storing data locally using the browser's **Local Storage**, ensuring tasks remain available even after refreshing the page. :contentReference[oaicite:0]{index=0}

---

## 📌 Project Overview

The To-Do List Web App helps users organize their daily tasks efficiently. It provides an intuitive interface for managing tasks with features like marking tasks as completed, deleting tasks, filtering task status, and automatically saving tasks in the browser.

This project is ideal for beginners learning **DOM Manipulation**, **Event Handling**, and **Local Storage** in JavaScript.

---

## ✨ Features

- ➕ Add new tasks
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- 🔍 Filter tasks (All, Completed, Uncompleted)
- 💾 Local Storage support
- 📱 Responsive design
- ⚡ Instant updates without page reload
